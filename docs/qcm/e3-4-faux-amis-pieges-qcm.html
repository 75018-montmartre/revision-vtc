La fiche E3.4

Faux amis et pièges des QCM

Situation

Fiche E3.4, page 434

Un client dit : « Actually, I’d like to stop at the library first. I need to rest a little after this long journey. » Le chauffeur comprend « actuellement », « librairie » et « journée » : il se trompe trois fois.

Avant de répondre : ma confiance
QCM 1 « Actually » signifie :

QCM 1 : réponse A

Actually : en fait, en réalité (A). Actuellement se dit currently ou at the moment (B est faux) ; activement, actively (C est faux) ; évidemment, obviously (D est faux).

QCM 2 « Library » et « journey » signifient :

QCM 2 : réponse C

Library : bibliothèque ; journey : voyage, trajet (C). Une librairie se dit bookshop (US : bookstore) ; une journée, a day (A, B et D sont faux). To rest : se reposer, pas « rester ».

La règle à retenir

Actually : en fait ; library : bibliothèque ; journey : trajet ; to rest : se reposer ; eventually : finalement ; sensible : raisonnable.

Le piège

Se fier à la ressemblance avec le français. Les faux amis sont précisément les mots qui ressemblent.

Pour aller plus loin

« Eventually » veut-il dire « éventuellement » ?

Non : finalement, au bout du compte.
